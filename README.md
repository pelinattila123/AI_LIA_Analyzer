NextStepAI
Projektarbete i Python -  Pelin Korkmaz
Mål;
Jag började min utbildning till AI Developer för ungefär en månad sedan. Under den första tiden märkte jag att många studenter fokuserar på att hitta en LIA-plats, förbättra sitt CV och förbereda sig inför intervjuer. Därför bestämde jag mig för att skapa NextStepAI. Jag ville bygga ett program som kunde hjälpa användaren med dessa tre delar på ett enkelt sätt. Mitt mål var inte att skapa avancerad artificiell intelligens utan att använda de Python-kunskaper jag har lärt mig hittills för att lösa ett verkligt problem som många AI-studenter möter.
Metod;
Jag planerade programmet som ett menysystem med tre olika funktioner:
•	Hitta LIA
•	CV-analys
•	Intervjuträning
För att bygga projektet använde jag funktioner för att dela upp programmet i mindre delar. Jag använde även klasser och arv för att träna på objektorienterad programmering. Jag valde att använda JSON för att spara intervjusvar eftersom det är ett vanligt format för att lagra data. Jag använde också biblioteken random och json från Python. Under arbetets gång testade jag programmet flera gånger och rättade fel när de uppstod.
Resultat
Jag lyckades skapa ett program där användaren kan:
1.	Få förslag på företag för LIA.
2.	Göra en enkel analys av sina kompetenser.
3.	Träna på intervjufrågor.
4.	Spara sina intervjusvar i en JSON-fil.
Programmet fungerar enligt den plan jag satte upp i början av projektet.
Analys
När jag arbetade med projektet insåg jag att flera delar av Python behöver samverka för att skapa ett fungerande program. Jag använde funktioner för att göra koden mer strukturerad. Jag använde listor och loopar för att hantera information på ett effektivt sätt. Genom att använda klasser och arv fick jag bättre förståelse för objektorienterad programmering. Jag använde även JSON för att lagra data utanför programmet. Det gjorde att informationen inte försvinner när programmet avslutas.
Reflektion
Detta är mitt första större projekt sedan jag började utbildningen till AI Developer. I början kändes vissa delar svåra, särskilt objektorienterad programmering, arv och filhantering. Genom att testa olika lösningar och felsöka koden fick jag en bättre förståelse för hur Python fungerar. Det jag är mest nöjd med är att jag lyckades kombinera flera olika programmeringsmoment i ett och samma projekt. Om jag fortsätter utveckla projektet i framtiden skulle jag vilja:
•	lägga till fler företag,
•	skapa en mer avancerad CV-analys,
•	hämta information från externa datakällor,
•	och utveckla ett grafiskt användargränssnitt.
Genom projektet har jag fått en bättre förståelse för hur programmering används för att skapa praktiska lösningar och hur olika delar av Python kan användas tillsammans i ett större program.
Under arbetet med projektet stötte jag på flera utmaningar. De vanligaste problemen handlade om fel ordning i koden, problem med klasser och arv, saknade importer samt felaktiga indrag. Jag fick även lägga tid på att förstå hur JSON fungerar för att kunna spara intervjusvar i en fil. Genom att testa programmet steg för steg och felsöka varje del lyckades jag lösa problemen och få programmet att fungera som planerat.
