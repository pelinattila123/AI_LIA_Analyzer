NextStepAI
Projektarbete i Python - Pelin Korkmaz


Mål;
Jag ville skapa ett enkelt projekt som hjälper studenter att hitta LIA-plats, träna på CV och öva inför intervjuer. Programmet är gjort för nybörjare som just har börjat lära sig Python. Jag fokuserade på att använda enklare begrepp som klasser, arv, listor, loopar, funktioner och JSON. Syftet var att visa hur man kan bygga något praktiskt och lätt att förstå.

Metod;
Jag skapade ett projekt i tre delar: en separat JSON-fil med företag, ett Jupyter Notebook där allt förklaras steg för steg, och en README som beskriver projektet. Jag använde arv för att visa hur klasser kan dela kod med varandra. Jag använde också bibliotek som json, random och pandas för att läsa data och presentera den tydligt.
Projektet använder även JobTech API från Arbetsförmedlingen för att hämta aktuell information om jobbannonser inom Python.

Resultat
I projektet kan användaren:
1. Se företag som passar ett område som AI, Python eller Dataanalys.
2. Läsa information från en separat databas.
3. Få ett enkelt exempel på hur ett litet program kan byggas.
4. Förstå hur klasser och arv fungerar i praktiken.

Analys
Den viktigaste lärdomen var att dela upp koden i små delar. Det gjorde det lättare att förstå vad varje del gör. Genom att använda JSON kan vi lagra information utanför själva programmet. Genom arv kan vi återanvända kod och spara tid. Det visar hur Python kan användas för praktiska lösningar även när man är nybörjare.

Reflektion
Detta projekt är enkelt men lärorikt. Det visar att man inte behöver avancerad kod för att skapa ett användbart program. När man bygger ett projekt steg för steg blir det lättare att förstå varje del. Jag är nöjd med att ha skapat ett projekt som är lätt att läsa, lätt att ändra och passar för nybörjare.

Hur du kör projektet
1. Öppna mappen med projektet i VS Code.
2. Öppna filen nextstepai_notebook.ipynb.
3. Kör cellerna i ordning från första till sista.
4. För att ändra företagsdata, öppna filen companies.json.
5. Läs den här README-filen om du vill förstå projektet bättre.

Projektstrukturen
- nextstepai_notebook.ipynb: Jupyter Notebook med förklaringar och kod.
- companies.json: separat databas i JSON-format.
- README.md: beskrivning av projektet.
